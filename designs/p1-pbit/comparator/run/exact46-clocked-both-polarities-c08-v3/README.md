# Retained 46-instance comparator polarity reproduction — C08 V3

This package publishes a retained 46-instance `p1_comparator` **simulation
copy** and two static-input, 5 GS/s clocked transient runs. It closes one narrow
question: that exact generated source reaches opposite unloaded output states
for `+10 mV` and `-10 mV` differential inputs at the retained historical
harness's latch and track sample instants.

The executed source has `XRFB l=18.05u`. The source-backed comparator and Top
V3 instead have `XRFB l=18.5u`, so this package is not evidence for that current
source-backed lineage. The adjacent retained `p1_comparator.sch` is included
for custody but contains no `XRFB` device and is **not** the source parent of the
executed generated netlist. The earlier package wording that called these the
current schematic and source was incorrect; instance count alone does not bind
source identity.

The two portable decks preserve the executed circuit, stimulus, analysis,
measures, and explicit raw writes. Only private execution paths were rewritten:
PDK model and OSDI prefixes use `$PDK_ROOT`, the comparator include is local,
and the generated source's schematic-path comment is local. Native and portable
hashes are bound in `parent_bindings.txt`; logs and raws are execution originals.

## Harness

- IHP SG13G2 typical model sections, 27 °C, `VCC_HBT=2.5 V`, `VDD=1.2 V`.
- Complementary 200 ps-period clocks with 20 ps edges: a 5 GS/s decision cadence.
- Static preamplifier-source common mode near 1.44 V and 120 Ω series source
  resistors.
- Equal 1.44 V trim inputs.
- Transient step 2 ps, stop 1.2 ns, start 0.
- Latch sample at 900 ps, track sample at 1000 ps, extrema over 600–1000 ps.
- No explicit load on `PBIT_OUT`, `PBIT_RAW`, or `CLK_OUT_DIV`.

The plus/minus decks differ only in their identity comment, swapped `VAMP_P` /
`VAMP_N` DC values, and polarity-specific raw basename.

## Independently reproduced result

Both native raws contain 223 vectors by 677 points from 0 to 1.2 ns. Their
binary payload lengths are exact, every value is finite, and time is strictly
increasing. `C08-V3-FACTS.tsv` is regenerated by `verify.py` from the raw bytes.

| input | `PBIT_RAW` at 900 / 1000 ps | `PBIT_OUT` at 900 / 1000 ps |
| --- | --- | --- |
| +10 mV | 1.198376 / 1.198272 V | -6.444 / +6.646 µV |
| -10 mV | 3.475 / 3.242 mV | 1.200010 / 1.199989 V |

Across 600–1000 ps, the plus output remains within roughly -19.5 to +11.9 µV;
the minus output remains within 1.199977 to 1.200015 V. Neither crosses 0.6 V.
The raw extrema and sample values match all eight printed log measures per
polarity to the logs' precision.

## Evidence boundary

This is **unloaded static-polarity simulation-copy evidence**, not a loaded
dynamic decision test. It does not establish the source-backed 18.5 µm
comparator, pad or buffer drive, kickback, PVT or mismatch robustness, power,
entropy, top-level operation, or any P1 specification. Both logs retain one IHP
aggregate HBT self-heating warning:
`The temperature limiting function received NaN.` That warning is preserved,
not waived.

The decks use model includes, OSDI loads, and a control block, so this package
is native ngspice-46 evidence rather than normalized OpenADA evidence. No
engineering gate, signoff, tape-out readiness, or foundry acceptance is claimed.

## Verify

From this directory:

```sh
python3 verify.py
sha256sum -c SHA256SUMS
```

The verifier checks package hashes, portable-source transformations, exact
deck parity and source binding, native-log warnings and measures, raw structure,
all finite waveform values, exact sampled values and extrema, and full facts
table coverage. A new simulator run is new evidence and is not required to
verify this retained result.
