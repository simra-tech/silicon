# IHP__SoC1816: G1 guardian

G1 guardian (radiation-aware node guardian) is a mixed-signal test chip on the IHP SG13G2
open PDK (0.13 um SiGe BiCMOS). Die 1414 x 1414 um including the seal ring, 24 `sg13g2_io`
pads, planned for QFN24 board measurements. It holds a current-limiting breaker (shunt sense
amplifier, two clocked trip comparators, I2t timer, external N-FET gate driver), an HBT
temperature-to-frequency sensor, a thin/thick-oxide NMOS dose canary pair, plain and TMR upset
canary shift registers, a SiGe bandgap, a three-wire serial interface and a bare `npn13G2`
on pins.

- Category: Mixed-Signal; subcategory: SystemOnChip (`SoC`); ID 1816 (from IHP `gen_structure.py`).
- Top cell: `SoC1816` (the design top `g1_chip_top` of the source repository, renamed; geometry unchanged).

- `info.json` `sealring_x/y` are the die edge in um (1414.0), matching the 63/0 text label, as IHP's pre-check requires.
