## Exact change and geometry proof

Passivation 9/0, dfpad 41/0 and all 132 TopVia2 cuts per pad move with each
native pad. TM2 retains the old plate. TM1 adds the exact sweep of its native
four-bar frame; the central hole is not filled. No original drawn metal is
removed. Relative to the parent, TM1 adds 15,823.2 µm² and TM2 8,400 µm².
The 24 native pad definitions themselves remain unchanged.

The actual serialized candidate was independently inverted: reverse the 24
transforms and remove only the new bridge cell. This restored the signatures
of all 292 original cells, including original top-level shape and instance
records. All original **non-top** cells and all recursive labels are unchanged
without inversion. The saved audit's abbreviated `all_original_cells_unchanged`
key refers to that non-top test; the top's declared pad-instance movements
are covered separately by exact inverse equality. The independent swept-frame
proof uses an outer-rectangle sweep minus intersected holes, not the builder's
four-bar construction. One-DBU addition/removal negative controls were rejected.

The source placement projection changes only 24 pad origins and 24 BTerm
positions. Reversing these edits restores the original DEF byte-for-byte.
An actual OpenDB import/roundtrip retained 4904 instances and all original
connections. It is an **unrouted placement/interface projection**, not an
updated final routed database or shifted-pad RC extraction.
