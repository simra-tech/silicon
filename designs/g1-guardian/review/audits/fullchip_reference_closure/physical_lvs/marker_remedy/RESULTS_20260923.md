## Actual design-layer change

`g1_io_secondary_polyres_r1` adds one 1×2 µm PolyRes body;
`g1_io_rc_polyres_r1` adds 26 separate 1×20 µm PolyRes bodies. Each body is
independently the intersection of unchanged GatPoly, SalBlock, EXTBlock and
pSD, agrees with original source W/L, and does not overlap contacts. Every
other polygon layer and all native texts retain exact geometry. The source
changes only the subcircuit header name, with exact reverse equality.
Oversized and shifted marker controls are rejected by the body constraint.
This is a declared design-layer repair, **not an assertion that 128/0 is
fabrication-mask-inert**. The original public PDK library is untouched.

The independent head/metal graph removes only the intended device body from
the conductor representation; it does not modify GDS. It uses actual contact
and seven-metal/six-via connectivity, never labels as joins. RC has 26 positive
device edges, 27 distinct conductor nodes, two degree-one endpoint pins and
25 degree-two internal nodes in one connected path. The original source
contains 26 series W1/L20 records. Stock device combination independently
produces the matching W1/L520 reference and extracted records. No L520 source
device is substituted for that original chain.

The retained native text labels state `rppd r=7.938k`, while the original CDL
numeric R field is 5.239K for each RC segment. This repair holds both original
texts and original source fields; the stock class matches geometry parameters.
It does not establish that those legacy resistance labels agree with the
electrical compact model or qualify the RC clamp time constant.

## Exact remaining SecondaryProtection failure

The adapter changes only `XR1` to `R_G1_TAP_SYNTAX_XR1`; its complete node/model/
A/P suffix and reverse-transformed source bytes are identical. Both source
and physical views now have all four ports. W1/L2 RPPD, DANTENNA and DPANTENNA
are `Match` under unchanged stock semantics. The tap is `MatchWithWarning`:

| Parameter | Native | Original source |
|---|---:|---:|
| A, µm² | 9.0304 | 9.03 |
| P, µm | 53.120000000000005 | 12.02 |

Two corresponding tap-related nets remain `Mismatch`. No warning is promoted
to a pass and neither A nor P is copied into the source as a repair. The
resistor correction is therefore independently useful but does not solve
the substrate/guard model contract.

## Three explicitly proved purged dummies

Source-only hierarchy traversal identifies exactly `PAD12_EN.I0.MP0`,
`PAD14_SCLK.I0.MP0` and `PAD15_SDI.I0.MP0`, each the original W4.65/L0.45 µm
all-VDD PMOS. Current native input-pad aliases have zero all-layer polygon XOR
against the stock cell; all three placement transforms are bound. The native
gate is exactly 2.0925 µm². A label-free graph proves gate, both separated
p-diffusions, actual nwell body through its ntap/contact path, and the native
VDD pin are one conductor component. P-diffusion is not directly connected
to nwell by the graph construction. Pinned unconditional `purge_devices`
explains the native omission; no actual device is removed from the design.

Two distinct extraction-only reference candidates remove just the single
LevelDown definition line representing those three reachable occurrences,
one based on the original reference and one on the faithful tap-prefix view.
Inserting that exact line at its recorded byte offset reconstructs each
input byte-for-byte. Every other model, parameter, node and source statement
is retained. These references have **not been compared or adopted**; original
fullchip failures and complete canonical electrical/device geometry remain.

Representative commands use `flow/run.sh`, one CPU and recorded fresh resource
gates: `prepare_marker_candidate.py`, `run_marker_stock.py --cell rc --kind lvs`,
`run_dummy_proof.py` and `prepare_dummy_extraction_reference.py`. Each native
check has a 180-second watchdog; independent proofs have 120 seconds. Memory
is a declared reservation, not enforced by rootless cgroups v1.
