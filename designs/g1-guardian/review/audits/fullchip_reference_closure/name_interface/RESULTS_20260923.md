## Stock controls

The pinned IHP PDK `84374023ee8b4b126bebbba67fcbada0a9c0ff0b` stock
`run_lvs.py --layout_netlist ... --netlist ... --run_mode=deep` was used with
KLayout 0.30.9. All LVS script/rule hashes were held. This documented mode
loads a layout-side netlist and **skips physical extraction**. It isolates
the actual stock alignment/simplification/comparison behavior without
pretending to verify real layout geometry.

The small fixture is two cascaded CMOS inverters, four expanded MOS devices,
five nets and four top pins. Source-side leaf name is `LOGICAL_INV`; the
alternate layout-side name is `RETAINED_INV`. No ignore, correspondence hint,
implicit-net, relaxed-port, tap-disable or net-only option was used.

| Case | Actual result | Disposition |
|---|---|---|
| Same top and leaf names | Strict passed, 3.545 s | Four expanded MOS and four pins retained on each side |
| Different non-top leaf names; same top | Strict passed, 3.611 s | Both leaf circuits flattened; exactly four direct MOS, five nets, four pins; all pairs Match |
| Aliased leaf with deliberately wrong second-stage input | Strict failed, 3.391 s | Negative detection passed; four MOS remain each side, two device and four net mismatches |
| Different top names | Alignment failed, 3.632 s, exit 1 | Comparison not run; no LVSDB; no schematic counterpart for `OTHER_TOP` |

The mismatched-top run exposed a **misleading stock wrapper summary**: it
prints `Status PASS` while also reporting exit 1, three errors, no explicit
comparison signature, and no LVSDB. That summary is rejected. The original
logs, missing-report failure, runner receipt and explicit saved-data
disposition are retained. No deck or stock wrapper was patched.

The two positive controls and negative connection control show that this
stock alignment path can flatten the tested non-top name mismatch while
retaining and comparing its devices. They do not prove that every fullchip
hierarchy will align, establish fullchip throughput, or waive IO/device/net
discrepancies. The top-name-only view supplies the demonstrated naming
prerequisite without a `same_circuits` rule change.

The official [KLayout alignment reference](https://klayout.de/doc/about/lvs_ref_netter.html)
also describes flattening unmatched non-top circuits and default name-based
pairing. The installed-runtime controls above, rather than documentation
alone, establish the observed behavior for this pinned setup.
