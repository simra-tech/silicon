# R100 standalone 20-sample smoke screen

**20/20 passed** numerical/source controls, gain and frozen continuous-calibration
residual checks. These are simulated standalone schematic results, not joint
chain yield or complete PEX qualification. Seeds 41001–41020 were fixed before
launch; no samples were replaced or excluded. The original ideal-VREF/PTAT,
passive-load fixture and `cap_typ` protocol were retained.

| Result | Simulated value |
|---|---:|
| Completed OP points, including return controls | 720 |
| Gain range | 19.9254–20.0496 V/V |
| Worst supported-common-mode calibrated residual | 354.5 µV |
| Uncalibrated input-error population standard deviation | 718.903 µV |
| Sum of bounded per-sample solver wall times | 940.155 s |

Each sample retained 529 finite native queries across four temperature phases,
51 matching historical parameters and exact return-to-25 °C observations.
The audit established distinct samples and nonzero MOS/resistor variability.
Capacitor mismatch was **not qualified**: unchanged `cap_typ` is not a mismatch
ensemble. Six outside-common-mode points per sample remain diagnostic, not
silently included in supported-range coverage.

The [method control](R100_MC_METHOD_20260923.md) binds the source, ngspice 46,
image and PDK identities. Its selected historical worst seed 41039 remains a
separate control with 498 µV residual, only 2 µV below the limit; the more
comfortable first-20 maximum does not erase that narrow margin.

Saved-data analysis also reports all three OTA closed-loop input differences
and an algebraic drift budget at every point. These include finite gain,
loading and mismatch. Nominal-ratio reference, pedestal and main terms retain
explicit network remainders; they are **not intrinsic isolated OTA offsets or
causal variance attribution**. Three algebra controls passed.

An independent review found missing template/runtime-reference hash bindings
in the first partial aggregate auditor. The final auditor pins both. Five
regression tests passed, including mutated-template, runtime and source
rejection. The partial audit is retained; the final audit supersedes it.
