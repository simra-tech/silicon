  corrected terminal-name call passes. Its original script was reconstructed
  from the one-line change and verified byte-for-byte against the failed
  receipt's original script hash; the failure is retained separately.

## Reproduction and identities

Use the revision-specific saved `build_assembly.py`, contract and completed
receipt in the evidence directory. `run_geometry.py --run-id UNIQUE
--resource-gate GATE.json --cpu N` runs a bounded assembly; the pinned runtime
then runs `run_stock.py --candidate UNIQUE --kind drc|lvs --resource-gate
GATE.json`. `G1_RESULTS_ROOT` names the provisioned bulk-results directory.
Each saved stock receipt records the exact command and unchanged rule hashes.
Text exports redact only host path prefixes and carry separate original and
exported hashes. GDS is byte-identical to the original completed run.
