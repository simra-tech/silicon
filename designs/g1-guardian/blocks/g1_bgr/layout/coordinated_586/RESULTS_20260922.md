## Routing and return limitations

The420×132µm resistor pilot retains all399 fixed native resistor positions.
M2 escapes serve row0, M4 escapes row1, and M3 provides41 physical collectors:
40 electrical nets with a separate precision-VSS route role. There are2396
two-cut transition arrays. This is a connectivity-first pilot; global M3
collectors over resistor bodies and unequal branch lengths are not validated
for capacitance, matching, temperature or finite route resistance.

The24 XR16 VSS ends use the precision collector at y16.26µm. It joins general
VSS at local x16µm, between y15.06 and16.26µm. The actual XQ56 reference-emitter
connection and all other HBT return trees are **not run**. Guard/startup/output
reference returns must not create undeclared parallel stars in future assembly.
Two cuts do not establish equal current sharing or a hot/pulse reliability rating.
