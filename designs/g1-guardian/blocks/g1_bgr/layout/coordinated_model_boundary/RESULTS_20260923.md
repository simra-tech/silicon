# BGR published-M2-emitter-pin DC diagnostic

Moving the 301 emitter attachments to their published M2 pins changes VREF
by only **−26.142 uV (KPEX table) / −54.350 uV (LEF table)** relative to the
earlier conditional M1 view. It does not remove the large simulated routing
sensitivity. Neither view is a qualified parasitic model or an adopted source.

All values are **simulated** nominal DC operating points, not measurements,
startup/stability proofs, or full physical IR qualification. Canonical source586,
models, calibration, final native GDS6d86 and nine physical ports are unchanged.
The [boundary review](BOUNDARY_REVIEW_20260923.md) explains the geometric/model
distinction; the [prospective contract](EXTERNAL_PIN_CONTRACT_20260923.md)
defines the bounded checks.

## Exact scope and controls

Only the layer field of 301 source-bound emitter points changes M1→M2, at
the same x/y inside each native pin. All other device points, currents, source
terminals and coordinates remain held. The extraction geometry file is
byte-identical (`245ae1adfa73a0afb31e0acfc9ddf314d9c943c3e54f60a1baad3529146fa896`),
so no drawn metal/via is removed. All 399 resistor M1 attachment pairs remain
unchanged. No scalar `re`/`rc` subtraction, generic Cont resistance, card change,
or whole-net resistance correction is used.

The unchanged engine re-segments the graph around the moved ports: each new
mesh has 48,902 raw edges, 6,287 exact-zero edges, 42,615 positive edges and
33,410 contracted nodes. These are not forced to equal the earlier mesh counts.
Every new positive edge is independently checked against the raw endpoint/value
inventory and retained at exact binary64 precision. Both graphs preserve
55 source nets, nine macro ports, all 1,036 primitive calls including nine
grounded HBT dummies, and 329 byte-identical historical capacitor lines.
Full graph contraction reconstructs source586 byte-for-byte.

The fresh zero-R control passed in 9.696 s with exact original OP bytes,
all 2,842 model-parameter values and 3,885 raw current/polarity fields.
Both nonzero cases preserve all 2,842 parameters and complete all 3,355
selected-point / 33,410 full-node voltage observations with finite data.
Input hashes remain exact before/after. TEMP=TNOM=27 C was observed in each
log; conditions remain 3.3 V, seed44001, R4=0 V, IPTAT=1 V and external1 pF.

The tables are distinct resistance assumptions, not qualified process corners
or error bars. Current attribution uses actual local D/S voltage and the
representative-probe-qualified mapping; no MOS orientation classification
changes occurred. Resistor end/BN current attribution remains explicitly
excluded at the new split-node bias. Reduced supply current is not power-feed
capacity credit. The KCL values are numerical observations, not retrospective
physical acceptance thresholds.

Both leaves completed inside their 600 s watchdogs on separate one-thread
CPUs under the 50%-available-capacity policy. Peak sampled RSS was about
143 MB each; the 8 GiB reservations were not cgroup-enforced. No simulator
errors occurred. Both logs retain dynamic-gmin start/completion notes.

passed. External-pin preparation r1 failed by comparing graph cluster numbers

control-worker hash, before extraction. A fresh r2 ID used the already-passed
