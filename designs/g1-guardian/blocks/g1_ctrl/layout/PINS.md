# g1_digital macro pins (run7)

Pin table of the `g1_digital` macro of record (LibreLane run tag `run7`, `../reports/librelane_run7/`), generated by `../flow/pins_md.py` from `g1_digital.lef` (sha256 `7519083e4154ae9d…`). Macro size 360 × 360 µm, origin at the lower-left corner; coordinates in µm. Every signal pin is 1.2 V CMOS (`sg13g2_stdcell`, `VDD`/`VSS`); the only signals that continue into the 3.3 V domain do so through one `g1_ls_up` cell each (`../ls/`). Direction is from the macro's point of view. Destinations follow `../../../specification/G1_REGISTER_MAP.md` section 2 and the two `INTERFACE.md` files.

Signal pins: 44; power pins: 2 (`VDD`, `VSS`). Signal pins sit on the macro boundary (0.4 µm wide): north-edge pins on Metal2 (vertical access), east/west-edge pins on Metal3 (horizontal access). The pin placer chose the edges freely (no `FP_PIN_ORDER_CFG`); if the chip floorplan wants a different assignment, add a pin-order file to `../flow/config.yaml` and re-run the flow, gate-level simulation and signoff.

Chip-level timing constraints for this macro (clock definitions on `osc_clk`/`SCLK`, uncertainties, false paths, IO delays) are in `g1_digital_top.sdc`, with the rationale and the re-run of the dry-run STA in `TOP_SDC.md`.

The three 3.3 V-bound control bits need three `g1_ls_up` instances (`../ls/README.md`); no other pin leaves the 1.2 V domain. `en` is the pad-level-shifted `EN` (`p2c` of `sg13g2_IOPadIn`, 1.2 V), shared with G1_GATE. `osc_clk` is the only clock input besides `sclk`; both are declared asynchronous in `../flow/g1_digital.sdc`.
