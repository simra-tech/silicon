# R1 block interface contracts (0.1, 2026-10-20)

Binding for revision-2 work. A change needs a dated row here and in both block READMEs.

| Interface | Contract |
| --- | --- |
| AFE → ADC | Two differential outputs, 1.44 Vpp full input (80 % of the ADC ±0.9 V FS, D16; was 1.6 Vpp / ±1.0 V), common mode 0.6 V from the ADC `vcm2` port; load per side: top-plate CDAC 2.8 pF, 250 ns track window, top plate near 0 V at track start; settling within the track window: non-linear residual ≤ 0.25 LSB at 12 bits; the linear part (a gain error, ≤ ±0.03 % in r1_afe revision D) is removed by the ADC gain/weight calibration and does not count (change 2026-10-20 after revision D: total error 0.38 LSB at the worst corner, 0.25 LSB total needs an output buffer above 1 mA; the host calibration must be re-run or temperature-compensated, since the linear part drifts up to about 0.4 LSB over temperature). |
| isense → ADC mux | Differential ±0.85 V at 0.60 V CM (revision 2, 2026-10-21: 0.600–0.601 V, MC σ ≤ 4.1 mV; was ≈ 0.57 V in revision 1; gain 14, 40.38 mV pedestal); sampled at the centre strobe `is_smp_a/b` from `r1_ctrl`; same CDAC load as above. |
| isense → safe | The isense differential output drives the four window comparators directly (OC_A, NEG_A, OC_B, NEG_B). |
| safe → ctrl | Four asynchronous flags `oc_a, neg_a, oc_b, neg_b` (active high = input above the cell threshold, 1.2 V domain after level shift); threshold codes `thr_oc[5:0]`, `thr_neg[5:0]` per channel (NEG cell code = 63 − `thr_neg`) and per-comparator offset-calibration codes `cal_oc_a[5:0]` etc. stay register words in ctrl (`CMP_THR_*`, `CMP_CAL_*`); **since ctrl 0.5 (2026-10-21) the macro no longer outputs them: it outputs the tap indices `tap_p[31:0]`, `tap_n[31:0]` (nP, nN, 8 bit per comparator, comparator i = 0 OC_A, 1 NEG_A, 2 OC_B, 3 NEG_B at [8i +: 8]) computed with the `r1_safe` formula nP = 4c + ceil(d/2), nN = 4(63 − c) − floor(d/2), c = `thr_oc` (OC) or 63 − `thr_neg` (NEG), d = k_cal − 32, clipped to 0..252, registered, one tick after a change of thr, cal or the end of a search; r1_safe takes nP/nN as its inputs** (step VREF/252 = LSB/8, k = 32 no shift); `az_win` strobe from ctrl marks the isense auto-zero window; ctrl runs the calibration search in the zero-current time *after* `az_win` (change 2026-10-20 from T4b: during the window the isense output is not valid) with the gates off, all four comparators in parallel at `thr` = THR_ZERO = 14. Result (change 2026-10-20, ctrl revision 0.3, resolves the mismatch below): two-sided search, k_cal = 32 + round((k_rel + k_trip)/2 − k_ideal), k_ideal = 36.31 (OC) / 27.69 (NEG), implemented as 32 + floor((k_rel + k_trip − `CMP_CAL_IDEAL`)/2) with `CMP_CAL_IDEAL` = 72 / 55 half codes; per decision ctrl applies a preset code (0 for the release pass, 63 for the trip pass) and then the probe code, ≥ 16 ticks each (`AZ_CFG.CAL_STEP`, reset 32 ticks); 14 PWM periods per search. The four code adders, the tap-index adders and the search live in ctrl (ctrl 0.5: `r1_tapidx`); the analog block exposes the tap-index inputs only. |
| ADC → ctrl | Per conversion: 14 raw decision bits (12 + 2 redundant, D17) and `valid`, both slices in parallel (own comparator and sequencer); ctrl computes code = Σ b_i·w_i with host-loaded weights `w[13:0]` (14 bit each); conversion ≤ 17 ticks; frame = 22 ticks at 30 MHz for the encoder pair {SIN, COS} (14 decisions at one per tick, ≥ 250 ns track); the current pair {ISA, ISB} replaces one encoder frame per PWM period at the centre-of-on-time strobe (D18, change 2026-10-20; the 36-tick two-pair frame of D17 forced two decisions per tick and is withdrawn). Weights are per slice: 2 × 14 registers. ctrl ports added in revision 0.2: `cal_*` codes, `adcw` weights, `sc_pend`, sub-tick LAT. |
| ADC reference | ≈ 0.92 V at the CDAC from a unity-gain on-chip buffer fed by the bandgap (D16); revision 2 buffer 422 µA from 3.3 V with 31 900 µm² MIM settles to 1 LSB at ±0.88 V; revision 3 target 0.25 LSB. |
| osc → ctrl | `clk30` (23–39 MHz untrimmed at code 22, up to 54.9 MHz if the host writes code 0 at ff); `osc_trim[4:0]` reset 22 (D13); `osc_en`. STA closes at 42 MHz; a count outside the expected window sets the clock-fault bit. |
| bgr → all | `vref` 1.045 V (G1 lineage), `iptat`; threshold DAC reference for safe; T2F bias. **2026-10-26 (D20):** the raw `vref` is a ≈ 180 kΩ source qualified with 1 pF; only `r1_adc` (`r1_refbuf5` input filter) and `r1_t2f` (if it draws no current) connect to it. `r1_safe` (string 4.2 µA) and `r1_isense` (pedestal resistors) connect to `vref_b`, the buffered copy from `r1_bias` revision 2 (drive ≥ 50 µA, offset ≤ 2 mV; output impedance to be recorded by T9). |
| r1_bias → consumers (2026-10-21, T9, `r1_bias` revision 1d, schematic) | Cascoded PMOS legs from `r1_bgr` `pbias`/`pcasc`; every output **sources** a PTAT current into the consumer's own NMOS diode (tt/27 °C value; range over PVT and `rppd` corners in brackets): `ib_afe_s1`, `ib_afe_s2`, `ib_afe_c1`, `ib_afe_c2` → `r1_afe` `ib_s1 ib_s2 ib_c1 ib_c2`, 10.14 µA each (6.9–15.4 µA); `ib_is_a`, `ib_is_b` → `r1_isense` `ibias_a/b`, 5.07 µA (3.5–7.7 µA); `ib_sf_oa`, `ib_sf_na`, `ib_sf_ob`, `ib_sf_nb` → `r1_safe` comparator `ibias` pins, 5.07 µA each (3.5–7.7 µA); `ib_adc_ref` → `r1_adc` `r1_refbuf5` node `nb`, 5.07 µA (3.5–7.7 µA; r1_adc must replace its internal `Ibias vdda nb 5u` by a pin). Compliance: within 1 % from 0 V to ≥ 2.55 V (consumer pins 0.70–0.87 V). The ADC comparators and `r1_osc` keep their local `rppd` bias; `r1_t2f` takes `pbias`/`pcasc` directly from `r1_bgr`. Consumers route the current line (VSS-shielded), keep the diode at their mirrors and add no other DC load (`r1_bias/README.md` "Bias-line decoupling"). Consumer decks that used ideal constant sources (AFE 10 µA) must re-run with this PTAT range. |

## Open contract mismatches (2026-10-20, found at the round-2 review)

| Interface | Mismatch | Resolution |
| --- | --- | --- |
| safe → ctrl, calibration search | `r1_safe` revision 3 (README and `sim/cal_model.py`) defines the result as k_cal = 32 + round((k_rel + k_trip)/2 − k_ideal) with k_ideal = 36.31 (OC) / 27.69 (NEG) at cell code 14 (NEG 49, i.e. `thr_neg` = 14), a two-sided search so the hysteresis cancels. `r1_ctrl` revision 0.2 (`rtl/r1_cmpcal.v`) does a one-sided successive approximation and stores the raw toggle code. Applied as is, the OC threshold shifts by about 4.3 steps (0.54 LSB) plus half the hysteresis, so the 0.25 LSB criterion fails. | **Resolved in ctrl revision 0.3 (2026-10-20).** `rtl/r1_cmpcal.v` runs both passes (release with preset 0, trip with preset 63; 6-bit SAR + check each, 14 windows) and stores 32 + floor((k_rel + k_trip − IDEAL2)/2) with the new register `CMP_CAL_IDEAL` (0x3C, 7 bits per type in half codes, reset 72 / 55). A 6-bit integer IDEAL (36 / 28) was evaluated and rejected: 103 of 274 samples one code off. Evidence: Python model of the RTL search vs `r1_safe` `cal_model.py` on the DC MC (51 + 51), corner (5) and transient MC (30) data, 274/274 identical k_cal; RTL on the same comparator tables 274/274 identical to the model (`r1_ctrl/README.md` revision 0.3). Mismatch **closed by r1_ctrl 0.3**; contract note in `r1_safe/README.md` ("Calibration contract with r1_ctrl 0.3", 2026-10-21). Hysteresis in calibration steps (2026-10-21, DC sweep): tt 1.94, ss 125 °C 2.79, ff −40 °C 1.56 steps (MC σ 0.1); the two-sided average leaves at most 0.71 step (0.089 LSB) of quantisation error. Still open on the `r1_safe` side: comparator delay at small overdrive vs the 32-tick probe time (not run). |
| ADC → ctrl, decisions and slices (found by T5 at ctrl revision 0.3, 2026-10-20) | The revision-0.2 ctrl port had one 13-bit `adc_raw` with one `adc_valid`, 13 weights and sequential conversions through `adc_mux`, against 14 decisions and two parallel slices in D17/D18. | **Resolved in ctrl revision 0.3 (2026-10-20, D18):** two 14-bit raw ports `adc_raw_a/b` with `adc_valid_a/b`, one `adc_start` and `adc_sel` for both slices; weights per slice 0x50–0x5D and 0x60–0x6D, all CRC-covered (ctrl decision); 22-tick encoder frame, the current frame at the strobe replaces one encoder frame and restarts the frame grid; `r1_pos` 19 ticks per pair. Binding for `r1_adc` revision 4: conversion ≤ 17 ticks from the `adc_start` pulse to the later `valid`; raw[13] = first decision; weights in 1/4 LSB. Evidence: `r1_ctrl/README.md` revision 0.3, run `r1ctrl_20261020_v03`. |
| ADC → ctrl, weights and frame | r1_adc revision 3 needs 14 weights per slice (28 registers); r1_ctrl revision 0.2 has one set of 13–14. The D17 36-tick frame was arithmetically impossible at one decision per tick (R3 frame-arithmetic note). | D18 schedule above; ctrl revision 0.3 implements the 22-tick encoder frame, the stolen current frame at the PWM centre strobe and 2 × 14 weights; r1_adc revision 4 returns to one decision per tick. |
| AFE/isense → ADC, input common mode | The 0.6 V comparator-input common mode was never checked against the ADC comparator's resolvable range; r1_adc revision 4 found decision 0 unresolved at ss/125 °C/1.08 V. | Contract stays 0.6 V (AFE revision E and isense are in layout at 0.6 V); r1_adc revision 5 changes the comparator input stage or the sampling CM. |
| ADC → ctrl, first conversion | r1_adc revision 5: the first conversion after the ADC is enabled is wrong (113 LSB at ss). Cause found by T2 (2026-10-21): the bootstrap capacitor of the SIN/COS sampling switch charges only while the switch is in hold. The ADC idles in track (`adc_hold` = 0 in reset), so the first track window after enable or reset (or after any long idle) starts with an uncharged capacitor. The switch then does not track inputs near VDD. | **Binding (replaces the discard rule):** after reset or ADC enable, ctrl drives `adc_hold` = 1 (hold) for ≥ 1 tick (33 ns), then ≥ 250 ns track before the first sampling edge. Simulated with this sequence: frame 0 equals frame 1 within 1 LSB (ss/125 °C/1.08 V at −0.90 V with a 10, 33 or 67 ns pulse; tt at 0 V); without it, +123 / +107 LSB (r1_adc README, revision 5, T2 rows; `sim/results/r5/firstconv5.json`). No ADC netlist change. r1_ctrl 0.5 item: put the hold tick into the reset exit of `r1_gate`. Until r1_ctrl implements it, ctrl discards the first conversion. **Implemented in r1_ctrl 0.5 (2026-10-21, `r1_gate`; run `r1ctrl_20261021_v05`, test `disc`):** after the reset release and after every rising edge of `ANA_CTRL.ADC_ARM`, once no frame is converting, `adc_hold` is high for 2 ticks (no `adc_start`, no `smp_sh`), then at least 11 ticks (262 ns at 42 MHz; 20 ticks = 667 ns at the default `PAIR_TICKS` 22 and 30 MHz) of track before the first frame. In addition the discard stays on as a second layer: `ADC_CFG.DISCARD` (0x3D, reset 1) drops the first frame after a reset or an arm event (both slices, both frame types; the dropped pair reaches neither the position path nor the current path). With the pre-charge confirmed on the ADC side the host may write `DISCARD` = 0. The ADC-side closed-loop run with the ctrl sequence is not run. |
| isense pedestal vs bandgap ground (2026-10-26, T4, layout c) | `r1_isense` derives its 40.38 mV pedestal from `vref` against its own `vss` pins; `r1_bgr` grounds `vref` on the core ring. A 9.4 Ω vss trunk from the ring to the isense pins (try-e estimate by square count) moves the pedestal by −408 µV at the output (loops and offset unchanged; `r1_isense/README.md` "Chip-level context"). | Open: `r1_top` keeps the shared vss resistance between the bandgap ground and the isense `vss` pins ≤ 2.3 Ω (wider trunk or a dedicated vss line to the bandgap ground), to be shown on the extracted try-f supply network. |
| VREF buffer (2026-10-26, T10 full-chip testbench, finding R1) | No block buffers `vref`; the chip-level netlist settles at 0.22 V with the safe string and the isense pedestals on the raw bandgap output. The safe record had assumed an ideal buffered source. | Decision D20: `r1_bias` revision 2 adds `vref_b`; `r1_top` try f routes `vref_b` to safe and isense; safe and isense decks re-run with the recorded buffer output impedance. |
